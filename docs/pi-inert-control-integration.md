## Fixed Local Child and Private Transport

The shared dormant policy constructor removes the provider-home writable bind, refuses aliases and
overlapping grants, and appends read-only home/code mounts after existing writable grants. It adds
no project/Git/cache/tmp grants. The fixed child launcher checks the entrypoint pin, the captured
MCP entrypoint digest and each explicitly supplied candidate import before launch. This is a byte
check of supplied paths, not proof that a complete import graph was loaded from immutable mounts.

Both the namespace launcher and package-free entrypoint get fixed scrubbed loader environments.
A four-byte length prefix bounds the private environment frame to 262144 bytes before JSON parsing.
It accepts an exact versioned shape, bounded keys/values and only fixed HOME/PATH/LANG plus captured
Wollipog transport keys. Node/ELF loader keys cannot enter the MCP child environment. The executable,
loader flags, MCP entrypoint and selector never come from a tool request. Environment values never
enter argv, temporary files or refusal messages. The private frame is stripped before subsequent RPC
traffic reaches the helper; stream backpressure, per-line byte limits, EOF and early exit are bounded.

The spawn-shaped adapter accepts only its captured selection/environment and the exact stdio shape.
It connects the generated extension to the fixed launcher in inert fixtures. The ordinary generated
source retains its original Node spawn import and emitted body. No provisioning or driver path
calls the inactive factory or launcher. Cancellation preserves the existing MCP acknowledgement
contract; the launcher kills and proves the local child tree before returning abort/timeout/failure.
It never retries outside the boundary. Cancellation of a remote request is not proof it wrote nothing.

## Evidence and Prerequisites

Transport tests run actual Node entry/helper processes with synthetic HOME and no inherited provider
environment. They exercise private-frame fragmentation, arbitrary RPC round trips, malformed and
oversized input, output bounds, open-input early exit, cancellation, descendants, modified/mutable
code and failures without retry. The generated-source fixture uses an explicitly named inert event
registry across each role and startup/reload/new/resume/fork reasons. It proves generated-source and
transport behavior, not actual Pi lifecycle reconstruction.

A separate opt-in test imports only pinned installed Pi 0.85.0 SDK loader/event contracts. This
implementation host's package cannot resolve `@earendil-works/pi-server`, an independently probed
prerequisite of that loader's import chain. This exact condition is reported UNAVAILABLE; other
import/runtime failures fail. No dependency is downloaded, patched or substituted. The independent
generated-source test is not a fallback that makes the installed-SDK test pass. Actual Pi CLI,
authentication, credentials, provider network requests and model inference are never exercised.

The OS fixture uses the production isolation resolver and actual outer/inner namespace launch.
It first verifies protected Git config and provider temp-rename refresh/transcript/config writes,
then denied MCP-child create/overwrite/delete/rename/alias/descendant writes, unchanged reads,
allowed worktree writes and cancellation. Named namespace setup denial is UNAVAILABLE, never a
pass. The implementation host refuses the outer namespace. Synthetic installation/runtime audit
seams are explicitly labeled and cannot establish real Pi installation or loaded-code coverage.

Before any production wiring or protected report, a fresh design/review must establish complete
immutable runtime/import provenance and in-namespace mount/loaded-byte identity before imports,
the actual packaged Pi/runtime launch and every enabled route, transitive control-plane effects,
and successful same-topology conformance. Unsupported hosts/versions/overrides or unproven routes
must retain supported ordinary launches with truthful unprotected/unknown disclosure. Once a future
launch is attested, a narrower command's failure must remain closed. Claude strict command sandbox,
Codex externalSandbox mediation, ACP coverage and other hosts remain original #3922 obligations.
